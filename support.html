자주 묻는 질문

다운로드 주소(dl.nooki.ink)가 안 열려요

최근에 등록한 도메인이라, 일부 회사·기관 네트워크의 보안장비가 새 도메인을 낯설다는 이유로 잠시 막아두는 경우가 있습니다. Nooki 사이트나 파일 자체의 문제는 아닙니다. 개인 네트워크(집 와이파이, 휴대폰 테더링 등)로 다시 시도해보시거나, 잠시 후 다시 열어보세요.

무료로는 뭘 할 수 있고, Pro는 뭐가 다른가요

무료로는 메모 3개까지 자유롭게 쓸 수 있고, 서식(굵게·기울임·밑줄·취소선, 글씨체·크기·색), 점 목록과 체크리스트, 미리 담긴 배경색, 검색, 휴지통(7일 보관), 라이트·다크 테마, 투명도 조절, 자동 숨김, 수동 백업(저장·내보내기·복구)까지 됩니다.
Pro는 메모 개수 제한 해제, 잠금, 즐겨찾기, 고정(핀), 원하는 색 직접 고르기, 사진, 링크, 파일 링크, 메모마다 크기 따로 기억, 보관함, 캘린더, 플로팅(메모를 따로 띄우기), 알림, 자동 백업, 전역 단축키(Alt+Space)를 더합니다. 한 번 결제(12,400원)로 계속 쓸 수 있고, 설치 후 14일은 무료판에서도 Pro 기능을 전부 체험할 수 있습니다.

14일 체험이 끝나면 만들어둔 것들이 사라지나요

아니요. 체험 중에 만든 메모, 걸어둔 잠금, 즐겨찾기 등은 그대로 남습니다. 새로 만들거나 새로 거는 동작만 다시 무료 범위로 돌아갑니다.

Pro는 어떻게 구매하고 켜나요

Pro 기능을 누르면 뜨는 안내에서 '구매하기'를 누르면 결제 페이지로 이동합니다. 결제 후 받은 라이선스 키를 트레이 아이콘 우클릭 → 설정 열기 창의 빈칸에 붙여넣고 '활성화'를 누르면 바로 Pro로 전환됩니다.

라이선스 키 하나로 몇 대까지 쓸 수 있나요

컴퓨터 3대까지 쓸 수 있습니다. 4대째에서 활성화하려 하면 이미 3대에서 쓰고 있다는 안내가 뜹니다. 컴퓨터를 바꾸실 때는 설정창에 나타나는 '이 컴퓨터에서 해제'로 안 쓰는 컴퓨터를 정리하면 자리가 비워집니다. 해제하면 그 컴퓨터에 넣어둔 키도 함께 지워지므로, 그 컴퓨터에서 다시 쓰려면 키를 한 번 더 붙여넣어야 해요.

인터넷 연결이 꼭 필요한가요

아니요. 메모 작성을 비롯한 대부분의 기능은 인터넷 없이 그대로 씁니다. Pro 사용자는 구매 여부만 확인하기 위해 켤 때와 이후 12시간마다 짧게 통신하는데, 연결이 안 되는 동안에도 최대 30일까지는 Pro가 그대로 유지되고 다시 연결되면 저절로 확인됩니다.

Pro를 구매했는데 기능이 잠겨 있어요

라이선스 키를 넣으면 이미 열려 있던 메모창에도 바로 반영됩니다. 그래도 잠긴 채로 남아 있다면 프로그램을 껐다 다시 켜보시고, 그래도 안 풀리면 nooki.support@gmail.com 으로 알려주세요.

메모가 다른 컴퓨터나 휴대폰에서도 보이나요

아니요. 메모는 사용 중인 컴퓨터 안에만 저장되고, 다른 기기와 자동으로 동기화되지 않습니다. 다른 컴퓨터로 옮기시려면 설정창의 백업(내보내기 · 복구) 기능을 이용해주세요. 자세한 저장 위치는 개인정보처리방침에 적어두었습니다.

Microsoft Store로 산 것과 웹사이트에서 산 것이 다른가요

지금은 새로 구매하실 때 웹사이트 결제 한 가지만 있습니다. 예전에 Microsoft Store에서 구매하신 분은 계속 그대로 쓰실 수 있습니다. 스토어로 설치한 경우 스토어가 알아서 업데이트하고, 웹사이트에서 받아 설치한 경우 앱을 켤 때마다 새 버전이 있는지 확인해 화면 가운데로 알려드립니다.

업데이트는 어떻게 하나요

웹사이트에서 받아 설치하셨다면, 새 버전이 있을 때 실행 중 알림이 뜨고 눌러서 확인하면 앱 안에서 바로 받아 설치됩니다. 브라우저를 열거나 설치 파일을 따로 받을 필요가 없습니다. 트레이 메뉴의 '업데이트 확인'으로 언제든 다시 확인할 수도 있습니다. Microsoft Store로 설치하셨다면 스토어가 알아서 업데이트합니다.

메모 잠금이 파일을 암호화하나요

아니요. 잠금은 비밀번호를 되돌릴 수 없는 형태로 저장해 다른 사람이 화면을 봤을 때 내용을 가려주는 용도입니다. 파일 자체를 암호화해 완벽히 숨기는 기능은 아닙니다.

환불 안내

결제 후 문제가 있거나 마음이 바뀌셨다면, 결제하신 이메일과 사유를 함께 nooki.support@gmail.com 으로 보내주세요. 사유를 확인한 뒤 환불 가능 여부와 절차를 안내해드립니다.
