Nooki 개인정보처리방침

최종 업데이트: 2026년 8월

한 줄 요약 — Nooki는 작성하신 메모·일정·사진을 인터넷으로 전송하거나 외부 서버에 저장하지 않습니다. 모든 내용은 사용하시는 컴퓨터 안에만 남습니다. 유료 기능 확인을 위한 통신 외에는 인터넷에 연결하지 않습니다.

1. 수집하는 개인정보

Nooki는 회원가입, 로그인, 계정 생성 절차가 없으며, 이름·이메일·전화번호 등 어떠한 개인 식별 정보도 수집하지 않습니다.

2. 메모·일정·사진 데이터의 저장 위치

작성하신 메모, 일정, 첨부한 사진은 전부 사용자 PC의 다음 위치에만 저장되며, 외부로 전송되지 않습니다.

  • 메모·일정 내용: 사용자 PC의 앱 데이터 폴더 (예: %APPDATA% 하위)
  • 첨부 사진: 위와 같은 폴더 내 별도 하위 폴더

이 데이터는 앱을 삭제하면 사용자가 직접 폴더를 지우기 전까지 남아 있을 수 있으며, 저희는 이 데이터에 접근할 방법이 없습니다.

3. 잠금 비밀번호

메모 잠금 기능에 사용하는 비밀번호는 원문이 아니라 되돌릴 수 없는 형태(해시)로 변환되어 로컬에만 저장됩니다. 이 기능은 정보를 암호화해 완벽히 숨기는 것이 아니라, 다른 사람이 화면을 봤을 때 내용을 가리는 용도입니다.

4. 네트워크 통신

Nooki는 클라우드 동기화, 자동 업데이트 확인, 사용 통계 수집, 광고 목적으로는 인터넷에 연결하지 않습니다.

다만 유료 기능(잠금·백업/내보내기·플로팅·캘린더·알람·즐겨찾기·보관함) 사용을 위해 구매 여부만 확인하는 통신을 합니다 — Microsoft Store를 통해 구매하신 경우 Microsoft에, 자체 웹사이트에서 구매하신 경우 결제 대행사(라이선스 검증 서비스)에 구매 확인을 요청합니다. 이때 메모 내용 등 사용자가 작성한 데이터는 전송되지 않습니다.

5. 제3자 제공

메모·일정·사진 등 사용자가 작성한 내용은 수집하지 않으므로 제3자에게 제공하거나 판매하지 않습니다. 구매 확인 과정에서는 위 4항에 명시된 결제 확인 목적으로만 최소한의 정보(라이선스 키 등)가 해당 서비스에 전달될 수 있습니다.
